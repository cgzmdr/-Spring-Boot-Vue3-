## 二、人口数据（2020 年第七次全国人口普查）

- 口径：2020 年 11 月 1 日零时第七次全国人口普查。
- 主来源：《中国人口普查年鉴-2020》表 2-1《全国各民族人口及比重》（国家统计局发布）。
- 校验方法：
  1. 与《第七次全国人口普查公报（第二号）》公布的汉族人口 **1,286,311,334** 人、少数民族合计 **125,467,390** 人核对一致；
  2. 56 个民族人口合计与年鉴表 2-1 合计 **1,409,778,724** 人（含未定族称人口 836,488 人）核对，误差在 OCR 识别误差范围内（±5 万人，集中在人口少于 5 万的小民族）；
  3. 与维基百科/新闻媒体转载的七普分民族数据抽样比对一致（如壮族 19,568,546、回族 11,377,914、满族 10,423,303、苗族 11,067,929 等）。
- 备注：
  - 高山族人口为**大陆地区**统计数据（3,479 人，不含台湾地区）；
  - 数据库中 `population` 字段统一使用 2020 年七普数据；
  - 民族概况文本中引用的「2010 年人口」出自国家民委官网原文（六普口径），仅作历史对比参考。

## 三、民族概况文本（国家民委官网）

- 每个民族抓取 4 个栏目：概况（人口、分布、自称、语言、文字）、历史沿革、风俗文化、发展现状。
- 概况文本源自《民族问题五种丛书》之《中国少数民族》卷（国家民委组织编纂的权威民族志）。
- 数据库 `description`（民族简介）为**数千字长篇**：合并「概况 + 历史沿革 + 风俗文化」三栏目官方全文（约 5,000–16,000 字/族，平均约 11,000 字），并以 `【历史沿革】`、`【风俗文化】` 小节标题分段；风俗文化部分天然涵盖各族**传统节日与饮食习俗**（如哈萨克族「那吾肉孜」新年与奶制品、回族开斋节与盖碗茶等）。
- `summary` 采用概况首段（约 110 字内按句断句）；`description_en`、`summary_en` 为基于官方内容编写的英文版本。
- 前端民族详情页「概况」标签按段落渲染长文：`【…】` 行显示为小节标题（强调底色 + 左侧色条），首段保留首字下沉（dropcap）。
- 除民族主表外，还基于国家民委「风俗文化」栏目与权威资料为每个民族补充了完整的内容矩阵：
  - **民族节日 166 条**（每族约 3 个代表节日，含日期/起源/习俗）
  - **传统艺术 164 项**（每族约 3 项，标注世界/国家/省级非遗级别）
  - **风俗习惯 112 条**（每族 2 条：礼仪/服饰/饮食/信仰等）
  - **民族美食 168 道**（每族 3 道代表美食）
  - **聚居地 112 处**（每族 2 处，含坐标，供「聚居地」地图/时间线展示）
  - 使网站「概况 / 风俗 / 节日 / 艺术」等板块均有真实内容可展示。

## 五、图片资源（Wikimedia Commons）

### 5.1 采集方式
- 通过 Wikimedia Commons API（`generator=categorymembers` + `prop=imageinfo`）按民族分类（如 `Category:Miao`、`Category:Clothing of Tibet`、`Category:Zhuang people` 等）检索，优先「服饰 / 人物 / 传统场景」子分类。
- 筛选条件：JPEG/PNG/WebP、宽 ≥ 900px、高 ≥ 600px、宽高比 0.5~2.2、排除地图/旗帜/徽标/图表等非照片内容。
- 每族下载 2 张候选（`cover.jpg` 主图 + `cover2.jpg` 备选）。

### 5.2 本地化处理与存放架构
- 统一转换为 JPEG，最长边 ≤ 1200px，质量 82%，用于网页展示（懒加载、压缩体积）。
- 共 56 个民族 × 封面图 109 张（其中 53 族含 2 张：`cover.jpg` 主图 + `cover2.jpg` 备选），合计约 31 MB。
- **图片组织原则（业务图片归后端，各端静态资源归各包）**：
  - **业务图片（民族/节日/艺术封面）→ 后端**：`backend/src/main/resources/static/images/ethnic/{slug}/`，由 Spring Boot 从 `classpath:/static` 以 `/images/...` 路径对外提供（`http://localhost:20256/images/ethnic/{slug}/cover.jpg`）；
  - **C 端自有静态资源 → 前端包**：`public/`（favicon、icons、占位图 `public/images/placeholders/placeholder.jpg`）；
  - **后台自有静态资源 → 后台包**：`admin/public/`（logo 等）；
  - 前端包中不再存放业务图片副本（已移除 `public/images/ethnic`、`admin/public/images/ethnic`）。
- **前端访问路径**：数据库 `cover_image` 存相对路径 `/images/ethnic/{slug}/cover.jpg`；
  - 开发环境：C 端与后台的 vite 代理已将 `/images` 转发到后端 `http://localhost:20256`（见 `vite.config.ts`）；
  - 生产环境：Nginx 需将 `/images` 反向代理到后端（与 `/backend-api` 同理），例如
    `location /images { proxy_pass http://localhost:20256; }`。
- **占位图本地化**：原 C 端 `CoverImage` 兜底使用远程 AI 生成图（`coresg-normal.trae.ai` 网络接口），
  现改为本地占位图（`public/images/placeholders/placeholder.jpg`，取材自真实民族照片），
  `src/utils/format.ts` 的 `aiImage()` 已不再请求任何外部图片服务；
  `design/` 目录设计稿中的全部网络图片引用也已下载并替换为本地文件（`design/images/placeholder.jpg`）。

### 5.3 许可说明（重要）
- Wikimedia Commons 仅收录**自由许可**或公有领域作品，主流许可包括 **CC BY / CC BY-SA / CC0 / 公有领域（PD）**，均允许非商业与商业使用，但 **CC BY / CC BY-SA 要求署名**。
- 本毕设仅作**非商业教学展示**；正式答辩展示或上线前，请按各图片的许可要求在页面添加署名（作者 + 许可 + 来源链接）。
- 每张图片的完整授权信息（作者、许可类型、Commons 页面链接、原图链接）已记录在采集清单中：
  - `scripts/scrape/tmp/commons2/manifest.json`（采集原始清单，含 `title / license / artist / page`）
- 若需完全规避署名义务，可仅选用 CC0/公有领域图片，或改用自摄/原创图片。
